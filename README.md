Spotify Track Popularity Analytics

Spotify Track Popularity Analytics is a data preparation and statistical analysis project that analyzes Spotify track-level data to identify measurable factors associated with track popularity. The project covers data cleaning, missing-value and duplicate handling, outlier treatment, feature engineering, title sentiment analysis, exploratory data analysis, correlation analysis, feature selection, and hypothesis testing using t-test, ANOVA, and Chi-square. The findings are presented through an interactive dashboard.
